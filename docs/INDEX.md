# Traceability Registry

Tracks versions, epics, statuses, and impacted components. Updated by the Project Manager
(versions), the Product Owner (epics), and the Solution Architect (story/epic status).

## Versions

| Version | Status | Scope | Objective |
|---|---|---|---|

## Epics

| Epic | Version | Feature | Status | Impacted components |
|---|---|---|---|---|

## Work items

Planned stories (US_$j), bug work items (BUG_$n / DEPLOY_BUG_$n) and blocker-mandated fixes
(FIX_$k). Bugs are scoped to the epic, not to the story they were found in.

| Work item | Epic | Title | Status | Commit |
|---|---|---|---|---|
